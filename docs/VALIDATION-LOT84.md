# Lot 84 — Rubriques Optiver conservées

Le collecteur aplatissait la description vérifiée en un paragraphe. Il conserve
désormais les paragraphes, listes et titres, sans code de page, attributs actifs
ou liens. Le bloc reste délimité par le collecteur ; le titre, l'identité, les
métadonnées et la pagination gardent leurs contrôles.

Les missions viennent d'une seule rubrique reconnue, terminée par un autre titre
employeur vérifié dans le même bloc. Une introduction éventuelle reste attachée
au premier élément pour conserver les conditions. Les sous-listes sont complètes.
Une structure ambiguë, un bloc caché, une borne absente, plusieurs rubriques ou
des conditions après la liste laissent la description complète disponible.

Les indications de diplôme viennent des rubriques de qualification auditées.
Préférences, négations et alternatives restent dans l'extrait original : il ne
s'agit pas d'une inférence d'éligibilité.

## Mesure sur les annonces réelles

Lecture publique de 27 fiches le 27 septembre : **17 missions et 10 indications
de diplôme supplémentaires**. Le texte complet, les identifiants et tous les
scores sont identiques avant/après. Exemples vérifiés :

- [SSO Floor Trader à Chicago](https://www.optiver.com/join-us/jobs/trading/chicago/sso-floor-trader/) : missions et diplôme.
- [Institutional Trader à Chicago](https://www.optiver.com/join-us/jobs/trading/chicago/institutional-trader/) : missions et diplôme.
- [Trading Automation Specialist](https://www.optiver.com/join-us/jobs/trading/chicago/trading-automation-specialist/) : missions.

Les dix fiches dont les missions ne sont pas reconnues restent consultables
intégralement. Les stages, viviers de candidatures et postes exclus ne sont
pas promus par cette amélioration de présentation.

Une seconde collecte réelle sur copie réussit : 27 fiches, 40 requêtes, aucune
nouvelle annonce ni fausse date de modification, aucun score Optiver changé.
Le suivi et les alertes sont conservés. La validation d'ensemble et l'installation
sont suivies dans le [bilan des deux lots](VALIDATION-LOT85.md).
