# Lot 68 — Études Société Générale et filtres Bac+4 / Bac+5

## Périmètre audité

Les 31 fiches Société Générale conservées ont été inspectées. Le collecteur
préserve le champ de profil dans un paragraphe distinct, avec son titre visible.
La lecture exige un paragraphe unique commençant par **Et si c’était vous ?**
ou **Profile required**. L'extrait conserve tout le profil, sans sélectionner
une phrase au détriment de ses conditions.

La limite de 1 500 caractères d'extrait reste applicable : les quatre profils
plus longs restent consultables dans la description complète. Les paragraphes
ambigus ou non reconnus ne produisent pas d'observation. Les autres formats
de Société Générale et les paragraphes non étiquetés des autres employeurs
ne sont pas extrapolés.

Les nouveaux filtres **Bac+4** et **Bac+5** correspondent aux mentions exactes de
ces niveaux dans les rubriques auditées. La formulation **Bac+4/5** est conservée
et rend la fiche visible dans les deux filtres. Aucun Bachelor ou Master n'est
déduit de ces nombres ; aucune obtention du diplôme n'est présumée. La formulation
française explicite **de type master** est reconnue dans cette source. Les
préférences, négations, conditions de fin d'études et alternatives restent visibles.

## Impact sur sauvegarde restaurée

- 787 offres, dont 31 Société Générale : 17 nouvelles fiches avec critères d'études.
- Une fiche mentionne Bac+4 et Bac+5, une autre Bac+5 ; dix comportent une mention
  de Master. Les catégories peuvent se cumuler dans une même fiche.
- Couverture totale : 166 offres avec diplôme ou niveau d'études. Les 168 fiches
  avec missions et toutes les observations antérieures sont conservées.
- Les 11 tables et tous les modèles d'offre restent identiques : scores,
  candidatures, dates, alertes et historique inchangés.
- Les 787 cartes Telegram restent valides, avec un maximum de 1 170 unités UTF-16.
  Aucun envoi ni modification d'une ancienne alerte.
- Les stages et titres Associate seuls restent exclus ; les intitulés explicitement
  ouverts aux deux niveaux gardent les autres critères habituels.

## Vérifications locales

- 38 tests ajoutés : mentions Bac+4/Bac+5, absence d'équivalence supposée,
  profils complets, préférences, alternatives, faux nombres, structures ambiguës,
  contenus masqués, périmètre par source, nouveaux filtres et suivi Postulé.
- Parcours navigateur sur copie : Société Générale + Bac+4 (une offre), détail
  Assistant Algo Trader ; Bac+5 (deux offres) ; Master (dix offres), détail
  Junior FX EM Trader, Analyst (94/100), alternatives Bachelor/Master conservées.
  Les deux stages Bac+4/Bac+5 conservent leur score nul. Aucune erreur JavaScript.
- Ruff, formatage et vérification des types réussis ; dix tests JavaScript réussis.
  Suite complète Windows : 3 553 tests réussis, quatre ignorés.
